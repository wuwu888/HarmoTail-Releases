# HarmoTail

HarmoTail 是面向 HarmonyOS 的原生 Tailscale 客户端。


## 主要功能

- 原生 HarmonyOS VPN 接入
- Tailscale 官方控制面连接
- Tailnet 设备查看
- Exit Node
- DNS 状态与设置
- 多账号支持
- Taildrop 文件传输
- Taildrive
- 应用分流
- 设备认证状态与到期提醒
- Tailnet Lock 状态查看
- 技术支持报告

## 当前核心版本

- Tailscale Core：v1.102.4
- OpenHarmony Go Runtime：Go 1.26.6

## 问题反馈

邮箱：

`harmotail@163.com`

遇到连接、登录、DNS 或文件传输问题时，可在 HarmoTail：

**设置 → 技术支持 → 导出支持报告**

并将报告随问题描述一同发送。
